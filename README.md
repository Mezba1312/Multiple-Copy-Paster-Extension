# Multiple-Copy-Paster-Extension


## 📌 Project Overview

**Simple! – Quick Notes & Clipboard Manager** is a lightweight browser extension designed to make storing, accessing, and reusing frequently needed text easier and faster.

The extension provides approximately 10 independent note slots where users can write or paste important text, formulas, equations, and other frequently used information. Each note has its own Copy and Clear buttons, allowing users to quickly copy stored content or remove it whenever needed.

Instead of repeatedly searching for the same information or switching between different applications, users can keep their frequently used text in one convenient place and access it directly while browsing different websites.

## ✨ Key Features

### 1. Multiple Note Slots
- Provides approximately 10 independent text storage fields.
- Write or paste different types of information into each field.
- Keep frequently used text organized in one place.

### 2. Quick Copy Functionality
- Each note has an individual Copy button.
- Copy text instantly with a single click.
- Easily paste copied content into other websites, applications, or text fields.

### 3. Individual Clear Option
- Each note has its own Clear button.
- Remove unwanted content without affecting other notes.
- Manage individual notes independently.

### 4. Multiple Text Format Support
- Supports English and Bangla text.
- Store mathematical formulas and equations.
- Store chemical reactions and other text-based information.

### 5. Browser Accessibility
- Access notes directly through the browser extension popup.
- Use stored information while visiting different websites.
- Reduce repetitive typing and improve productivity.

### 6. Data Persistence
- Notes remain available even after closing and reopening the browser.
- Currently, notes do not persist after restarting the computer.

## 🎯 Use Cases

This extension can be useful for:

- Students storing mathematical formulas, chemical equations, and study notes.
- Developers keeping frequently used code snippets or commands.
- Researchers saving frequently used text and references.
- General users storing repetitive messages and commonly used information.
- Anyone who frequently copies and pastes text across different websites.

## 💡 Why Simple!?

The main goal of this extension is to save time and simplify everyday browsing activities.

By providing multiple independent note slots with instant Copy and Clear functionality, Simple! makes frequently used information accessible without requiring users to open a separate note-taking application.
